# Frontend - Campos de Airsoft (React & Vite)

Aplicación web desarrollada en React con Vite para la gestión y consulta de campos de airsoft conectados a la API REST.

## Cómo levantar el frontend

1. Entrar a la carpeta del proyecto: `cd mi-app`

2. Instalar dependencias: `npm install`

3. Crear un archivo .env en la raíz de mi-app con la URL/puerto de la API:

4. Iniciar el servidor de desarrollo: `npm run dev`
